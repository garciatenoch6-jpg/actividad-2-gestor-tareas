# TaskFlow - Gestor de tareas

Aplicación web para organizar actividades, desarrollada con HTML, CSS y JavaScript como parte de la Actividad 2 de Desarrollo Full Stack.

## Funcionalidades
- Agregar, editar y eliminar tareas.
- Marcar tareas como completadas o pendientes.
- Filtrar tareas por estado.
- Consultar un resumen de tareas.
- Guardar los cambios en LocalStorage para conservarlos al recargar el navegador.
- Diseño adaptable a computadoras y dispositivos móviles.

## Tecnologías y conceptos
- HTML5 y CSS3 con media queries.
- JavaScript ES6+: `const`, `let`, funciones flecha y template literals.
- Programación orientada a objetos: clases `Tarea` y `GestorDeTareas`.
- Manipulación del DOM y eventos.
- Arreglos y `forEach`.
- LocalStorage y JSON.

## Ejecutar localmente
1. Descarga o clona este repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` con Live Server.
4. Prueba las operaciones y recarga la página para comprobar la persistencia.

## Archivos
- `index.html`: estructura de la interfaz.
- `styles.css`: estilos y diseño responsivo.
- `app.js`: clases, lógica, eventos y almacenamiento.

## Publicación
El proyecto puede publicarse desde **Settings > Pages**, seleccionando la rama `main` y la carpeta `/(root)`.
